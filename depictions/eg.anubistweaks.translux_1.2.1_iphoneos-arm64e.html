TransLux — RootHide

Description

Advanced translation integration for iOS with OCR support (DEBUG BUILD with enhanced logging). Adds translation buttons to text selection menus across all apps. Includes Snapper 3 integration for image OCR and translation. Supports Google, Baidu, ModernMT, Microsoft translation engines and Youdao, Yandex OCR engines. Features customizable UI, app whitelist.
